# 中文口型自动生成系统

面向游戏剧情配音的中文自动口型方案：导入配音音频与台词文本，按拼音声韵母切分音素与时间，
映射为 14 个口型，生成可编辑的面部动画曲线，并在 three.js 三维角色上实时预览。

核心算法为纯 TypeScript（不依赖 DOM/Web Audio），浏览器 UI 与 Node 批量管线共用同一套代码，
保证结果一致、可复现。

## 需求对应

| 需求 | 实现 |
| --- | --- |
| 英文音素插件不支持中文 | 自建拼音体系：声母/韵母/声调解析，内置约 500 字词典 + 语境词表，支持多音字 |
| 张嘴比声音晚 2-3 帧 | 10ms 帧移的 Viterbi 强制对齐，边界量化误差 ≤10ms，干净音频均值误差约 31ms（< 一帧 33.3ms） |
| 八千句手 K | 批量管线，实测吞吐约 25 万句/小时（目标 500） |
| 每句误差 ≤ 一帧（33ms） | 干净音频 81.7% 边界落在一帧内；对齐均值 30.6ms |
| 声母韵母自动切音素和时间 | `pinyin.ts` 拆音素 + `alignment.ts` 强制对齐出时间 |
| 十几个口型 | 14 个中文口型（sil/AA/EH/OH/OO/IU/ER/ZH/ZS/JB/LD/DT/GG/QX） |
| 儿化/轻声/连读合并、不抖 | 儿化并入前字、轻声压低、同口型相邻段合并、3 帧中值滤波去抖 |
| 三维预览 + 拖关键帧改 | three.js 变形目标头部 + Canvas 时间线，关键帧可拖拽并吸附 30fps 网格 |
| 换方言/重录自动重算 | 音频内容指纹（audioHash）+ voiceProfile 双因子判定，变化即重算 |
| 混背景音乐/音效也要准 | 自适应 VAD + 稳态 BGM 否决 + 瞬态抑制 + 鲁棒主语音区间，噪声下一帧内 59.3% |
| 配音和角色样本自己生成 | 纯 TS 共振峰合成器（声门源+双二阶共振峰），同时输出真值边界用于精度验收 |

## 目录结构

```
src/core/        纯 TS 核心库（浏览器/Node 通用）
  types.ts       领域模型与常量（16k 采样、30fps、10ms 帧移、14 口型）
  dictionary.ts  拼音词典与语境词表（多音字/轻声/儿化例外）
  pinyin.ts      分词、变调（一/不/三声/叠词）、儿化、音素与口型映射
  audio.ts       WAV 编解码、FFT、分帧特征、自适应 VAD
  alignment.ts   锚定窗口 Viterbi 强制对齐
  curve.ts       口型段合并、协同发音交叉过渡、去抖、关键帧稀疏化/重建
  synth.ts       共振峰语音合成、BGM/SFX 混合、4 种配音 profile
  pipeline.ts    端到端编排、音频指纹与重算判定
  accuracy.ts    对齐精度评估（对合成器真值边界）
  samples.ts     24 条样本台词 + 批量基准词库
src/ui/          three.js 预览 + Canvas 时间线编辑器 + Web Audio 播放
src/cli/         Node 命令行（生成样本/批量/基准/精度）
test/            vitest 测试（37 个用例）
```

## 快速开始

```bash
npm install
npm test          # 37 个单元/精度测试
npm run dev       # 启动三维预览与编辑器（Vite）
npm run build     # 类型检查 + 生产构建
```

命令行：

```bash
npm run cli -- generate-samples data/samples     # 生成 24 句配音 WAV（含带噪版）
npm run cli -- accuracy                            # 完整精度评估（6 个场景）
npm run cli -- benchmark 200                       # 200 句吞吐/对齐分基准
npm run cli -- batch data/samples/manifest.json data/output
```

## 精度与吞吐（本仓库自测，合成音频）

`npm run cli -- accuracy`：

| 场景 | 均值误差 | P95 | 一帧(33.3ms)内占比 |
| --- | --- | --- | --- |
| 干净·男声 | 30.6ms | 161.6ms | 81.7% |
| 噪声·男声（BGM+3 SFX） | 69.7ms | 281.9ms | 59.3% |
| 干净·女声 | 41.9ms | 182.3ms | 73.4% |
| 干净·方言 | 48.2ms | 239.6ms | 73.6% |
| 噪声·方言 | 253.8ms | 1361ms | 38.9% |
| 干净·重录 | 31.7ms | 171.5ms | 79.7% |

`benchmark 200`：约 25.7 万句/小时，单句平均约 13ms。

> 说明：精度数字基于内置共振峰合成器输出的真值边界。合成音频音素边界清晰、可控，
> 用于验证算法正确性与回归；接入真实人声音频时，建议先用 `pinyinOverride` 校准词典，
> 并按录音环境调整 VAD 门限（`audio.ts` 的 `runVAD`）。

## 对齐算法要点

`alignment.ts` 采用左到右 HMM + Viterbi：

1. **自适应 VAD**：相对噪声底的滞后门限 + 频谱通量稳态 BGM 否决，切出主语音区间；
2. **锚定期望进入帧**：发音状态按先验时长比例映射到主语音区间，静音状态不设锚点；
3. **联合代价**：帧级声学失配（过零率/质心/浊音/能量）+ 对数高斯时长先验 +
   flux 边界吸附奖励 + 锚定窗口惩罚，把单状态误差限制在局部、杜绝跨句累积漂移；
4. **最小帧数约束 + 回溯兜底**，保证每个音素都有时间区间。

## 口型与去抖

- 相邻同音 viseme 自动合并；不同 viseme 间用 50ms cosine 交叉淡入模拟协同发音；
- 儿化 er-cap 与主元音叠加而非替换；轻声整体压低权重；
- 逐路 3 帧中值滤波 + 0.06 死区清零，消除单帧抖动；
- 关键帧采用容差抽点（RDP 式），可在 0.08 容差内稀疏化并忠实重建。

## 已知边界

- 内置词典聚焦样本与常用字，生僻字走占位读音并在 `warnings` 报告，可用 `pinyinOverride` 或 `registerReadings` 扩展；
- 强噪声（20% BGM + 多个 SFX）下方言场景仍有较大尾段误差，真实项目可结合更强的降噪前端；
- 程序化头部用于验证驱动逻辑，生产中可把 14 路权重接到自有角色的 BlendShape 控制器。
